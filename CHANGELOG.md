# 📝 Changelog

## Version 2.0.0 - iOS-Inspirerad Design (2026-08-06)

### 🎨 Stora Designförändringar

#### Ny UI/UX
- ✨ **Helt ny iOS-inspirerad design** - Minimalistisk och professionell
- 🔘 **Två separata knappar** - ON och OFF istället för en toggle
- 💫 **BlurView-effekter** - Frosted glass iOS-stil på knappar
- 🌈 **Gradient bakgrund** - Smooth dark gradient som ändras med state
- 🔦 **Custom ficklampikon** - Grafisk representation med glow-effekt

#### Nya Visuella Effekter
- ⚡ **Glow-animationer** - Pulsande effekt när lampan är tänd
- 🎭 **Smooth transitions** - Mellan alla states
- ✨ **Shadow effects** - Elegant depth och dimension
- 🎯 **Status indicator** - Tydlig "TÄND"/"SLÄCKT" text

#### Förbättrad UX
- 👆 **Tydligare knappar** - Separata ON/OFF för bättre användarupplevelse
- 📱 **iOS-liknande känsla** - Som Apple's egna ficklampsapp
- 💡 **Visuell feedback** - Immediate response på alla actions
- 🎨 **Konsekvent design** - Allt följer iOS design guidelines

### 🔧 Tekniska Uppdateringar

#### Nya Dependencies
- `expo-linear-gradient` - För gradient bakgrunder
- `expo-blur` - För iOS-stil blur-effekter
- Animated API - För smooth animationer

#### Kodförbättringar
- Refaktorerad komponentstruktur
- Ny animation logic för glow-effekter
- Separata funktioner för ON och OFF
- Förbättrad state management

### 📚 Ny Dokumentation
- **[DESIGN.md](DESIGN.md)** - Komplett design guide
  - Färgschema och spacing
  - Komponentspecifikationer
  - Animationsdetaljer
  - User flow
  - Design principer

### ⚡ Performance
- Optimerade animationer med `useNativeDriver`
- Effektiv rendering med React hooks
- Minimal re-renders

### 🎯 Prank-Effektivitet
- **Mer professionell look** = Bättre trovärdighet
- **iOS-liknande design** = Användare litar mer
- **Subtil "200 kr" text** = Mindre uppenbar varning
- **Legitimate appearance** = Bättre prank! 😈
